First pre-release of the voice simracing coach for iRacing: the six milestones of the specification.

**Pre-release**: everything has been tested in synthetic replay and by CI, but nothing has run yet on a real PC with iRacing, a wheel and a microphone.

## Contents

`simcoach.exe` is a standalone executable: C runtime, sherpa-onnx and ONNX Runtime statically linked, no DLL to install. The archive also contains `plans/synthetique.toml` (example plan) and the README.

- Live iRacing telemetry and .ibt file replay, laps and corners
- Reference lap (Garage61 CSV or .ibt), per-corner deltas and metrics
- Cue engine with silence in braking zones, Piper `fr_FR-siwis` voice
- Embedded MCP server and ACP client (Claude, conversation on Haiku)
- Configurable push-to-talk (keyboard, mouse, wheel, button box, gamepad), Parakeet speech recognition
- Automatic planning of the next lap (analysis session on Sonnet)

## Requirements

- Windows 10 or 11, x64
- The Claude CLI logged in once with the subscription: `claude`, then `/login`
- The ACP adapter: `claude-agent-acp.exe` on the PATH, or Node.js (the program then runs `npx -y @agentclientprotocol/claude-agent-acp@0.107.0`)
- Internet access on first launch: the voice (about 80 MB) and speech recognition (about 670 MB) are downloaded from Hugging Face into `%LOCALAPPDATA%\simcoach\data\models`

## Getting started

```
simcoach.exe                         live iRacing telemetry
simcoach.exe --synthetic             demo without iRacing
simcoach.exe --reference "Garage 61 - ... .csv"
simcoach.exe --help
```

Set the push-to-talk button in the conversation panel (click the edit button, then press the button you want).

A console window opens with the application: it shows the log (detected devices, microphone, ACP adapter, errors), which is useful for these first trials.
