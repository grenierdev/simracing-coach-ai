Everything is now in English, and the voice language is a setting: English or French.

**Pre-release**: tested in synthetic replay and by CI; not yet run on a real PC with iRacing, a wheel and a microphone.

## Changes since v0.1.0

- **English throughout**: interface, command-line help, logs, error messages, coach prompts, code and documentation.
- **Voice language setting** (English by default): the **Voice** button in the conversation panel, or `--language en|fr`. It selects the text-to-speech voice (Piper `en_US-ljspeech`, public domain, or `fr_FR-siwis`) and the language Claude replies and writes cues in. Speech recognition (Parakeet v3) handles both languages without a setting. A change made in the interface applies on the next launch.
- **New plan file format** (breaking): `[settings]` and `[[trigger]]` with `text`, `corner`, `anchor` (`braking`, `entry`, `apex`, `exit`), `offset_m`, `position`, `priority`, `repeat` (`"once"`, `"every_lap"`, `{ laps = N }`), `condition`, `expire_after_laps`, `max_delay_m`. Plans written for v0.1.0 (`[reglages]`, `[[consigne]]`…) must be rewritten; see the README and `plans/synthetic.toml`.
- **MCP tools and their JSON results** use English names (`update_plan` takes `triggers` and `mode = "replace" | "add"`; `say` takes `when = "now" | "next_straight" | "position"`).
- The analysis session folder is now `sessions\analysis`. A French `CLAUDE.md` left by v0.1.0 in `sessions\conversation` is renamed `CLAUDE.v0.1.md` and replaced by the English default.
- Example plan renamed `plans/synthetic.toml`.

## Contents

`simcoach.exe` is a standalone executable: C runtime, sherpa-onnx and ONNX Runtime statically linked, no DLL to install. The archive also contains `plans/synthetic.toml` (example plan) and the README.

## Requirements

- Windows 10 or 11, x64
- The Claude CLI logged in once with the subscription: `claude`, then `/login`
- The ACP adapter: `claude-agent-acp.exe` on the PATH, or Node.js (the program then runs `npx -y @agentclientprotocol/claude-agent-acp@0.107.0`)
- Internet access on first launch: the voice of the selected language (about 80 MB) and speech recognition (about 670 MB) are downloaded from Hugging Face into `%LOCALAPPDATA%\simcoach\data\models`

## Getting started

```
simcoach.exe                         live iRacing telemetry
simcoach.exe --language fr           French voice and replies
simcoach.exe --synthetic             demo without iRacing
simcoach.exe --reference "Garage 61 - ... .csv"
simcoach.exe --help
```

Set the push-to-talk button in the conversation panel (click the edit button, then press the button you want).
