A simpler interface in three screens, with a compact coaching view that can stay on top of the game, and a choice of audio devices.

**Pre-release**: tested in synthetic replay and by CI; not yet run on a real PC with iRacing, a wheel and a microphone.

## Changes since v0.2.0

- **Three screens**, switched with tabs:
  - **Coaching**: coach state lights (*Listening*, *Thinking*, *Speaking*, *Analyzing*, *Idle*), rolling level meters for the coach's voice and your microphone, the reference lap with a quick **Load lap…** button, the live delta, the delta per corner (last lap, best lap, active cue), and the upcoming and last spoken cues.
  - **Chat**: the conversation, the coach's tool calls, every analysis summary with the analysis session's tool calls, laps and detailed corner metrics. The log follows new messages.
  - **Setup**: session, reference and plan, voice settings, devices, automatic planning, connection status.
- **Pin on top** (Windows): keeps the Coaching screen above the game in a compact 460 × 680 window; the choice is saved. Works over a borderless/windowed game, not over exclusive fullscreen.
- **Audio devices**: choose the push-to-talk microphone and the coach's output (e.g. headset for the coach, speakers for the game). The change applies immediately and is saved by device id; a missing device falls back to the system default with a note in the chat.
- A summary from the analysis session arriving during a coach reply no longer splits the reply in two.

## Contents

`simcoach.exe` is a standalone executable: C runtime, sherpa-onnx and ONNX Runtime statically linked, no DLL to install. The archive also contains `plans/synthetic.toml` (example plan) and the README.

## Requirements

- Windows 10 or 11, x64
- The Claude CLI logged in once with the subscription: `claude`, then `/login`
- The ACP adapter: `claude-agent-acp.exe` on the PATH, or Node.js (the program then runs `npx -y @agentclientprotocol/claude-agent-acp@0.107.0`)
- Internet access on first launch: the voice of the selected language (about 80 MB) and speech recognition (about 670 MB) are downloaded from Hugging Face into `%LOCALAPPDATA%\simcoach\data\models`

## Getting started

```
simcoach.exe                         live iRacing telemetry
simcoach.exe --language fr           French voice and replies
simcoach.exe --synthetic             demo without iRacing
simcoach.exe --help
```

Open **Setup** to set the push-to-talk button and the audio devices, then go back to **Coaching** and pin it on top.
