`simcoach.exe` no longer opens a terminal window.

**Pre-release**: tested by CI and in replay with a simulated race engineer. A real iRacing reset and the race engineer running with Claude on a real session have not been tested yet.

## Changes since v0.8.0

- **No terminal window**: the executable is now a Windows GUI program. Started from a terminal, it still writes its messages and `--help` to that terminal, but the terminal does not wait for it to exit. Started by double-click, its messages are not shown anywhere.

## Contents

`simcoach.exe` is a standalone executable: C runtime, sherpa-onnx and ONNX Runtime statically linked, no DLL to install. The archive also contains `plans/synthetic.toml` (example plan) and the README.

## Requirements

- Windows 10 or 11, x64
- The Claude CLI logged in once with the subscription: `claude`, then `/login`
- The ACP adapter: `claude-agent-acp.exe` on the PATH, or Node.js (the program then runs `npx -y @agentclientprotocol/claude-agent-acp@0.107.0`)
- Internet access on first launch: the voice of the selected language (about 80 MB) and speech recognition (about 670 MB) are downloaded from Hugging Face into `%LOCALAPPDATA%\simcoach\data\models`

## Getting started

```
simcoach.exe                         live iRacing telemetry
simcoach.exe --language fr           French voice and replies
simcoach.exe --replay "session.ibt" --reference "Garage 61 - ... .csv"
                                     replay of a recorded session against a Garage61 lap
simcoach.exe --synthetic             demo without iRacing
simcoach.exe --help
```

Export the reference lap from garage61.net as a CSV and load it with **Load lap…** on the Coaching screen, or with `--reference`. Open **Setup** to set the push-to-talk button, the audio devices and the volume. Once a reference lap is loaded, every turn you drive is analyzed; click **Widget** to open the widget, or let it open with iRacing.
